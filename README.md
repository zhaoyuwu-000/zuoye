# 个人主页示例网页

一个使用**原生 HTML + CSS + JavaScript** 编写的单页个人作品集页面

## 实现的功能

### 1. 顶部导航栏
- 固定顶部导航，包含「首页」「个人简介」「作品集」「留言」四个入口。
- 点击导航链接可平滑滚动到页面对应区块。

### 2. 深色 / 浅色模式切换
- 点击导航栏右侧「深色模式」按钮，可在深色与浅色主题之间切换。
- 通过切换 `<body>` 的 `data-theme` 属性 + CSS 变量（`--text-color`、`--bg1`、`--bg2`）实现配色切换。

### 3. 个人简介区
- 展示圆形头像和一段个人简介文字。

### 4. 作品集
- **自动轮播图**：三张图片每 3 秒自动切换一张，循环播放；通过 `setInterval` 定时触发，利用 `transform: translateX()` 配合 0.5s 过渡实现平滑滑动效果。
- **作品网格**：6 个作品卡片，使用 CSS Grid 三列布局；卡片可点击跳转到对应链接（第一个链接至 GitHub 作业仓库，其余为占位）。

### 5. 留言板
- 提供留言输入框和「提交」按钮的表单界面。

### 6. 页脚
- 预留的深色页脚区域。
